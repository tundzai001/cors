    Chọn dữ liệu ứng dụng cần đọc. Mã trạm (serial) luôn được trả về. Các trường bên dưới có giải thích cụ thể.

    Chọn phạm vi truy cập cho key
    KẾT NỐI API

    Hướng dẫn sử dụng

    1. Gửi yêu cầu đọc dữ liệu

    Gọi từ server của ứng dụng. Thay YOUR_API_KEY bằng key đã sao chép.

    
            
            
    2. JSON trả về
    
            
    Đây là dữ liệu minh họa theo quyền của key, không phải dữ liệu trạm thật. API trả một mảng trạm; trường chưa có dữ liệu có thể là null hoặc không xuất hiện. Không có trạm trong phạm vi thì trả [].
    
            
    
            
    
            
    3. Gửi yêu cầu sửa cấu hình
    Key này được sửa cấu hình. Thay SERIAL_TRAM bằng serial của trạm được cấp quyền. JSON dưới đây đổi mountpoint của Caster 1.
    Đổi cấu hình chip: POST đến , dùng cùng header Bearer và Content-Type: application/json. Body gồm command (lệnh chip hỗ trợ) và payload (tham số lệnh).
    
            
    401: key sai, hết hạn hoặc bị thu hồi. 403: không có quyền sửa trạm. Lưu key trên server của ứng dụng, không đưa vào mã trình duyệt.
    
        
    
        
    
        
    
            
    Xác nhận xem key
    Nhập mật khẩu của tài khoản admin đang đăng nhập. Key sẽ tự ẩn sau 30 giây.
