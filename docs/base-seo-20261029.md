## Triển khai và kiểm tra thực tế

Chưa triển khai: SSH tới máy chủ từ phiên làm việc này không xác thực được bằng khóa hiện có. HTML trang chủ production trước sửa khớp bản gốc trong repo.

Triển khai cùng phiên bản cho `backend/app/public_pages.py`, `backend/app/frontend_routes.py`, `backend/app/seo.py`, `frontend/index.html`, `frontend/js/dist/homepage-enterprise.v2.min.js`, `frontend/js/dist/blog-system.min.js` và `frontend/sitemap.xml`. Giữ file gốc để quay lại. Backend cần khởi động lại theo cơ chế vận hành hiện tại để nạp module Python mới.

Sau triển khai, xác minh HTML trả về qua HTTPS cho `/`, `/blog`, một bài viết và một trạm có thật: title/description đúng trang; canonical và URL chia sẻ khớp trang đích. Kiểm tra sitemap động và giao diện desktop/mobile. Nếu lỗi, khôi phục cùng bộ file cũ và khởi động lại backend.

Trong Google Search Console của `https://base.aitogy.com/`: kiểm tra URL trang chủ, canonical do Google chọn, yêu cầu lập chỉ mục lại và gửi sitemap `https://base.aitogy.com/sitemap.xml`. Theo dõi truy vấn `aitogy`, `aitogy base`, `hệ thống base aitogy`. Chưa có dữ liệu Search Console trong phiên này.

Thứ hạng và sitelinks do Google quyết định. Các thay đổi kỹ thuật này không chứng minh Base đã vượt website công ty. Liên kết nổi bật từ website công ty tới Base là bước riêng cần quyền sửa website công ty.
